## Scope and safety

All candidates are opt-in. The default, exact weights, single-token decode, non-PQ2 formats and unsupported GPUs retain their existing kernels. A failed native compilation or workspace reservation falls back to the existing path.
The original compact PQ2 weights remain unchanged. Full-K candidates temporarily requantize one matrix pair; they do not expand or cache the entire model.

Block modes preserve original half scales and exact integer weight codes. Their per-128 preparation/scaling overhead outweighed native matrix throughput in this campaign. Full-K INT8/FP8 use power-of-two row scales, adding weight and activation rounding.

## Matrix exploration

The existing Metal tensor path reads FP32 activations and stages decoded PQ2 weights as FP16. `half2` instead pairs scaled FP16 activations with original packed INT2 weight codes. The full-K FP8 and INT8 candidates use native low-precision operand tensors.

## Reproduction

Build the release tools and a clean-main `dump_geist_logits` executable (`CLEAN_MAIN_DUMP`), acquire the exclusive M6 host lease, then run:

```sh
python3 tools/tune_metal_pq2.py --out RAW/matrix
python3 tools/bench_metal_pq2_model.py --model BONSAI.gguf --out RAW/model
python3 tools/bench_metal_pq2_model.py --model BONSAI.gguf --out RAW/model-m512 --seq-lens 512,2048 --m-max 512 --skip-quality
python3 tools/check_metal_pq2_default.py --binary CLEAN_MAIN_DUMP --model BONSAI.gguf --model-results RAW/model
python3 tools/check_metal_pq2_replay.py --model-results RAW/model
python3 tools/check_metal_pq2_isolation.py --baseline-binary CLEAN_MAIN_DUMP --model QWEN3_Q8.gguf --model QWEN35_Q8.gguf --model LLAMA_Q4KM.gguf --out RAW/isolation
python3 tools/bench_revision_ab.py --rev base=origin/main --rev new=HEAD --gguf QWEN35_Q8.gguf --seq-lens 128,512 --warmup 512 --decode-n 32 --cycles 6 --env GEIST_BENCH_BACKEND=metal --env GEIST_METAL_TENSOR=1 --env GEIST_METAL_PQ2_MODE=off --out-dir RAW/revision-ab
python3 tools/report_metal_pq2.py --raw RAW --output benchmark/results/M6_PQ2.md
```
