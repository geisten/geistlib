### Added
- **GGUF MXFP4 weights (ggml type 39, #243).** GPT-OSS stores its experts
  in MXFP4: 32-element blocks of an E8M0 exponent byte and 16 nibble bytes
  indexing the E2M1 values. `GEIST_DTYPE_MXFP4` is appended directly above
  `GEIST_DTYPE_COUNT`, so no published dtype value moves.
  `dequant_mxfp4_row` is the reference decoder, bit-identical to ggml's
  `dequantize_row_mxfp4`. Native kernels: cpu_neon W4A8 GEMV and 4-token
  prefill (one `vqtbl1q` per 16 nibbles, SDOT), cpu_x86 on the IQ4 nibble x
  Q8_0 kernels (AVX2), Metal decode GEMV and simdgroup GEMM. cpu_scalar runs
  the reference; Vulkan the host row-dequant path (no shader yet).
